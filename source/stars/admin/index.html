首次创建管理员

不再需要 STAR_ADMIN_TOKEN，也不用 Termux 或 Wrangler。

为防止陌生人抢先注册，第一次设置必须证明你拥有 Cloudflare D1 数据库。

  1. 点击「复制授权 SQL」。
  2. 打开 Cloudflare → D1 → mywangzhan → 控制台，粘贴这条 SQL 并执行。
  3. 返回本页，设置至少 12 位的管理员密码，点击「创建管理员」。

授权码只在当前浏览器页面生成；如果刷新了页面，重新复制并执行新的 SQL 即可。初始化完成后授权立即作废。
